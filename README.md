# Repoka POS – Android

Bản cài đặt (APK) của app **Repoka POS** cho điện thoại Android.

## Tải bản mới nhất

👉 Vào mục **[Releases › Latest](../../releases/latest)**, tải file `.apk` trong phần **Assets**.

Cách nhanh hơn: trong app, vào tab **Thêm › Cập nhật ứng dụng**. Khi có bản cài mới, app hiện nút **Tải bản cài mới**.

## Cách cài / cập nhật

1. Mở file `.apk` vừa tải về.
2. Nếu Android hỏi, cho phép cài ứng dụng từ trình duyệt hoặc trình quản lý file.
3. Bấm **Cập nhật** (hoặc **Cài đặt**).

> **Quan trọng:** cài **đè** lên app đang có, **không gỡ app cũ trước**.
> Cài đè thì giữ nguyên máy tin cậy, đăng nhập, đăng nhập vân tay và giỏ hàng đang dở.
> Gỡ app rồi cài lại thì phải ghép máy tin cậy lại từ đầu.

## Cập nhật nhỏ không cần cài lại

Phần lớn cập nhật được tải tự động qua mạng khi mở app. Chỉ khi app có thêm tính năng cần phần cài đặt mới thì mới có bản `.apk` mới ở đây.

## Yêu cầu

- Điện thoại Android.
- Có mạng internet khi đăng nhập và lưu đơn.
